## Name

```
Underscore Highlighter
```

## Summary (250 chars max — keep short)

```
Highlight the web. Save passages to a library you can search, export, and sync.
```

## Description

```
Underscore Highlighter helps you keep the lines worth rereading.

HOW IT WORKS
• Select text on any page to save a highlight
• Browse your library by site and section
• Jump back to the source when you need context
• Search across quotes and domains

GUEST MODE (NO ACCOUNT)
• Start immediately—no sign-up wall
• Highlights stay on this device
• Clear local data anytime from Settings

SIGN IN WHEN YOU WANT MORE
• Sync your library across devices
• Use the web app alongside the extension
• Export on eligible plans (Markdown, spreadsheet)
• Optional AI uses keys you provide (BYOK) or local tools you enable

PRIVACY
• No third-party ad trackers in the extension
• Guest data stays local until you choose to sync
• Full policy: https://underscore-web-3i0.pages.dev/privacy

Underscore is for readers, researchers, and anyone who highlights faster than they can file.
```
