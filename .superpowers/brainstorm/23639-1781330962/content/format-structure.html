Exporting Highlights: Formats & Structure

Select your preferred export formats and content hierarchy. Previews of the layouts are shown below.

1. Choose Formats to Support

MD

Markdown (.md)

Obsidian, Notion, and Logseq compatible. Beautifully formatted text with links and notes.

TXT

Plain Text (.txt)

Universal, readable text format with simple margins and separators.

HTM

HTML Document

Interactive web page with modern styling, responsive layouts, search, and copy tools.

XLS

Spreadsheet (CSV/XLSX)

Tabular layout with headers: Domain, Section, Highlighted Text, Note, Color, Date.

PDF

PDF Document

Polished, print-ready layout with page numbers, title header, and clean margins.

2. Select Primary Structure / Hierarchy

A

Domain → Section → Underscore

Nested hierarchy. Groups highlights under their website domain, then groups by path (Section), then individual highlights.

B

Flat Timeline (Chronological)

A simple list ordered by date/time, showing host domain/url as a minor detail. Best for quick review of recent sessions.

C

Categorized by Tags/Colors

Groups highlights by Tag or Color role first, helping you organize research themes across different domains.
