Export UX: How do you pick a format?

When you tap "Export" in the extension popup, how should format selection work?

A

Format Picker Sheet

Tapping "Export" opens a bottom sheet with format buttons. One tap → picks format → file downloads immediately. Clean, explicit.

B

One-tap with Default Format

Export button fires immediately using a default format (set in Settings). Good for power users who always use the same format. A small "▾" arrow lets you override the format inline.

C

Inline Format Chips

The section/library footer shows small chips: MD · TXT · CSV. Tap any chip to download in that format immediately. No modal, no default — always all options visible.
